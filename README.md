# CaptionLab

Бесплатное браузерное приложение для добавления динамичных субтитров к видео. Приложение не требует Node.js: GitHub Actions публикует статические файлы на GitHub Pages.

## Публикация через Safari на iPad

1. Откройте `github.com/iliasshagiakhmetov-eng/reels-subtitles` и войдите в GitHub.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Source: GitHub Actions**.
4. Откройте **Actions**, выберите **Deploy CaptionLab to GitHub Pages** и дождитесь зелёной галочки.
5. Откройте ссылку из блока **deploy**: `https://iliasshagiakhmetov-eng.github.io/reels-subtitles/`.

После каждого изменения в ветке `work` публикация запускается автоматически. Выберите видео, введите текст и нажмите **Скачать субтитры**.
